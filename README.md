# 🏥 Hospital Management System

A Java-based Hospital Management System developed using JDBC and MySQL. The project manages patients, doctors, appointments, billing, prescriptions, emergency cases, feedback, and doctor schedules through a menu-driven console application.

## 🚀 Features

### Patient Management
- Add Patient
- View Patients
- Search Patient
- Update Patient
- Delete Patient
- Count Patients

### Doctor Management
- Add Doctor
- View Doctors
- Search Doctor
- Update Doctor
- Delete Doctor
- Count Doctors

### Appointment Management
- Book Appointment
- View Appointments
- Search Appointment
- Update Appointment
- Cancel Appointment
- Count Appointments

### Emergency Management
- Add Emergency Case
- View Emergency Cases
- Search Emergency Case
- Update Emergency Case
- Delete Emergency Case
- Count Emergency Cases

### Billing Management
- Generate Bills
- View Bills
- Update Payment Details
- Delete Bills

### Prescription Management
- Add Prescription
- View Prescriptions
- Update Prescription
- Delete Prescription

### Feedback Management
- Add Feedback
- View Feedback
- Update Feedback
- Delete Feedback
- Count Feedback Records

### Doctor Schedule Management
- Add Schedule
- View Schedules
- Search Schedule
- Update Schedule
- Delete Schedule
